# Protótipo do PetLive

Código-fonte das 102 telas e páginas do protótipo, mais o `canvas.json` com a posição de cada uma no canvas.

O protótipo navegável está em https://claude.ai/artifact/UFhxFUGwCYokbjPKCXDqKK. Estes arquivos são a referência de layout, textos e fluxos para a implementação. Eles não são o código do app.

Imagens de todas as telas: [imagens/README.md](imagens/README.md).

## Convenções

| Padrão de nome | O que é |
| --- | --- |
| `Welcome`, `Login`, `Main`, `Inicio`, `Pet`, `Mapa`... | App do tutor |
| `Loja`, `Produto`, `Servicos`, `Agendar*`, `Pagamento*`, `Passeio*` | Marketplace, lado do tutor |
| `Painel`, `Pedidos`, `Catalogo`, `Agenda`, `Horarios`, `Servico*`, `Loja*`, `Config*` | App do lojista (celular) |
| `Web*` | Painel do lojista (computador) |
| `Admin*` | Painel admin (computador) |
| `Site*` | Site do PetLive |
| `Encontrado` | Página pública do QR |

Os valores `[valor]` e `[Nome da loja]` são marcadores de exemplo.
